今のお金と未来のお金は違う：時間価値という発想

同じ金額でも、もらう時期によって価値が変わる――「お金の時間価値」という発想を直感でつかみます。

// この Topic のゴール
  • 「今すぐ100万円 vs 1年後105万円」の損得が世の中の金利で決まることを説明できる
  • 現在価値（PV）と将来価値（FV）を用語として使い分けられる
  • 機会費用の意味を自分の言葉で説明できる
📝確認クイズ（全 4 問正解で 次の Topic 解放）
Q1「今すぐ100万円をもらう」と「1年後に100万円をもらう」。どちらが得？（金利はプラスで、もらったお金はすぐ運用できるとする）
A今すぐの100万円
B1年後の100万円（待つほど価値が増えるから）
Cどちらも完全に同じ価値
正解: A
同じ金額なら、早く受け取って運用できる分だけ「今」の方が価値が高い。これが「お金の時間価値」の出発点です。
Q2「現在価値（PV）」と「将来価値（FV）」の説明として正しいのは？
APVは将来の金額、FVは今の金額
BPVは今の時点での価値、FVは将来の時点での価値
CPVとFVは同じ意味の言葉
正解: B
PV（現在価値）= 今の金額、FV（将来価値）= 将来の金額。複利公式 $FV = PV(1+r)^n$ はこの2つを結ぶ式です。
Q3「今すぐ100万円」と「1年後に105万円」。世の中の金利が10%のとき、得なのは？
A1年後の105万円（5万円多いから）
B金利に関係なく、いつでも1年後が得
C今すぐの100万円
正解: C
100万円を金利10%で運用すると1年後は $100 \times 1.10 = 110$ 万円。105万円を上回るので、今すぐ受け取る方が得です。
Q4「今、相手に100万円を渡す」ことの“機会費用”にあたるのは？
Aお金を渡すときにかかる振込手数料
B物価が上がって100万円で買える量が減ること
Cその100万円を運用していれば得られたはずの利息
正解: C
機会費用とは、ある選択をすることで失う「選ばなかった方から得られたはずの利益」。今お金を渡すと、運用して増やせたはずの利息を失います。

TOPIC 2

割引現在価値（PV）：1回だけのお金を「今」に換算する

未来のお金を「今の価値」に換算する公式 $PV = \dfrac{F}{(1+r)^n}$ を学びます。第4回の複利公式の逆操作です。

// この Topic のゴール
  • 1年後・n年後の F 円の現在価値の式を書ける
  • 割引が第4回の複利公式の逆操作だと説明できる
  • 具体的な金額の現在価値を電卓で計算できる
📝確認クイズ（全 4 問正解で 次の Topic 解放）
Q11年後にF円もらう予定があります。その現在価値PVは？（金利r）
A$PV = F(1+r)$
B$PV = \dfrac{F}{1+r}$
C$PV = F \times r$
正解: B
PV円を1年運用すると $PV \times (1+r) = F$ になる必要があるので、両辺を $(1+r)$ で割って $PV = \dfrac{F}{1+r}$。
Q2n年後にF円もらう予定の現在価値は？（金利r）
A$PV = \dfrac{F}{(1+r)^n}$
B$PV = F(1+r)^n$
C$PV = \dfrac{F}{1+rn}$
正解: A
複利公式 $FV = PV(1+r)^n$ を $(1+r)^n$ で割っただけ。n年分の割引なので分母は $(1+r)^n$ です。
Q3割引式 $PV = \dfrac{F}{(1+r)^n}$ と、第4回の複利公式 $FV = PV(1+r)^n$ の関係は？
Arを足したり引いたりしただけの別物
Bまったく無関係に新しく覚える公式
C複利公式の両辺を $(1+r)^n$ で割った“逆操作”
正解: C
割引は複利の逆操作。今→未来が複利（増やす）、未来→今が割引（縮める）。同じ式を逆から見ているだけです。
Q41年後の105万円の現在価値はいくら？（金利5%）
A100万円
B約105万円（ほとんど変わらない）
C約110.25万円
正解: A
$PV = \dfrac{105}{1.05} = 100$ 万円。トピック1の「今の100万円 = 1年後の105万円」が、式からきれいに確認できます。

毎年の現金フローを合計する：有限の等比数列の和

// この Topic のゴール
  • 毎年定額の現金フローの現在価値が等比数列の和になることを示せる
  • 等比数列の和の公式で現在価値の合計を計算できる
  • 退職金の一時金 vs 年金の損得を金利別に判断できる
📝確認クイズ（全 4 問正解で クリア）
Q1毎年定額CFを「1年後から」n年間もらう現金フロー（今日は受け取らない設定）。各年の現在価値を並べると等比数列になります。初項と公比は？
A初項 $CF$、公比 $(1+r)$
B初項 $\dfrac{CF}{1+r}$、公比 $\dfrac{1}{1+r}$
C初項 $CF$、公比 $r$
正解: B
各年の現在価値は $\dfrac{CF}{1+r}, \dfrac{CF}{(1+r)^2}, \dots$。初項 $\dfrac{CF}{1+r}$、公比 $\dfrac{1}{1+r}$ の等比数列です。最初の受け取りは「1年後」なので、初項は CF そのものではなく 1 年分割り引いた値になります（動画 T3 の設定と同じ・受け取りは年末払い）。
Q2$\sum_{t=1}^{n} \dfrac{CF}{(1+r)^t}$ が表す意味として正しいのは？
Atを1からnまで動かして、各年の現在価値 $\dfrac{CF}{(1+r)^t}$ を全部足し合わせる
BCFをn回かけ合わせる
Cn年後の現金フローの現在価値だけ
正解: A
Σは合計の記号。$t=1, 2, \dots, n$ の各年の現在価値を足した「現金フローの現在価値の合計」を意味します。
Q3退職金1億円。「一時金で今すぐ1億円」と「年金で1年後から毎年500万円を20年間（合計1億円）」。金利5%で得なのは？
A一時金（年金の現在価値は約6,231万円で、1億円を下回るから）
B年金（合計が同じ1億円なので損得は無い）
C年金（毎年もらえて安心なので得）
正解: A
年金の現在価値は $500 \times \dfrac{1 - 1.05^{-20}}{0.05} \approx 6{,}231$ 万円。一時金1億円の方が得です。
Q4上の退職金で、もし世の中の金利が0%だったら、一時金と年金はどちらが得？
A一時金
B年金
Cどちらも同じ価値（金利0%では割引が起きないから）
正解: C
金利0%だと $\dfrac{1}{(1+r)^t} = 1$ で割引が起きません。合計が同じ1億円なら一時金も年金も等価です。
