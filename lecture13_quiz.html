費用関数と限界費用 — あと1個でいくら？

費用関数を微分して限界費用 MC（あと1個の追加費用）を求め、平均費用（割り算）との違いと「規模の経済」を読めるようにします。

// このトピックのゴール
  • 費用関数 C(x) を固定費用＋可変費用として読める
  • 限界費用 MC = C'(x) を微分で計算し「あと1個の追加費用」と説明できる
  • 平均費用（割り算）と限界費用（微分）の違いを説明できる
  • 規模の経済（たくさん作ると平均費用が下がる）を読み取れる
①確認クイズ（全3問正解で トピック2 解放）
Q1費用関数 $C(x) = x^2 + 4x + 100$（万円、$x$ は個数）の限界費用 $MC(x)$ は？
A$2x + 4$
B$x + 4 + \dfrac{100}{x}$
C$x^2 + 4$
正解: A
限界費用は費用関数を微分したもの。べき乗の公式（前に出して1減らす）で $C'(x) = 2x + 4$。「あと1個作ったときの追加費用」を表します。
Q2平均費用 $AC$ と限界費用 $MC$ の違いとして正しいのは？
Aどちらも同じもので、呼び方が違うだけ
B平均費用は「総費用 ÷ 個数」（1個あたりのならし）、限界費用は「あと1個の追加費用」（微分）
C平均費用は微分で、限界費用は割り算で求める
正解: B
平均費用 $AC = C(x)/x$ は「これまで作った分をならした1個あたり」、限界費用 $MC = C'(x)$ は「いま、あと1個でいくらかかるか」。意思決定では「あと1個」を見る限界費用が効きます。
Q3費用が $C(x) = 100 + 2x$（固定費用 $100$ 万円＋1個 $2$ 万円）のとき、たくさん作るほど1個あたりの平均費用はどうなる？
A上がっていく——作るほど高くつくから
Bずっと一定で変わらない
C下がっていく（規模の経済）——固定費用をみんなで分け合うから
正解: C
$AC(x) = \dfrac{100}{x} + 2$。$x$ が大きいほど固定費 $100$ が薄まり、$AC(50)=4 \to AC(100)=3$ と下がる。これが規模の経済（ユニクロが大量生産で安くできる仕組み）です。
🔒 3問すべて正解すると トピック2 が解放されます。

利潤最大化 — P = MC と MR = MC

  • プライステイカーの利潤最大化条件 P=MC を導ける

①確認クイズ（全3問正解で トピック3 解放）
Q1市場価格 $P$ で何個でも売れる企業（プライステイカー）が利潤を最大にする条件は？
A$P = AC$（価格＝平均費用）
B$P = 0$（価格をゼロにする）
C$P = MC$（価格＝限界費用）
正解: C
利潤 $\pi(x) = Px - C(x)$ を微分すると $\pi'(x) = P - MC(x)$。一階の条件 $\pi' = 0$ は $P = MC$ と同じこと。「あと1個の儲け（価格）」と「あと1個の費用（限界費用）」が釣り合うところが最適です。
Q2ある独占企業の需要が $P = 100 - 2Q$、費用が $C = 20Q + 200$。$MR = MC$ で求める最適生産量 $Q$ は？（$MR = 100 - 4Q$、$MC = 20$）
A$Q = 40$
B$Q = 20$
C$Q = 50$
正解: B
これは第3回に平方完成で解いた独占の問題と同じ設定です。$MR = MC$ より $100 - 4Q = 20 \Rightarrow Q = 20$。このとき価格は $P = 100 - 40 = 60$、利潤は $600$。道具が平方完成から微分に変わっても、答えはぴったり一致します。
Q3プライステイカーと独占企業の「限界収入 $MR$」の違いとして正しいのは？
Aプライステイカーは $MR$ が価格 $P$ で一定、独占は売るほど $MR$ が下がっていく
Bどちらも $MR$ は売るほど上がっていく
Cプライステイカーだけ $MR$ があり、独占には $MR$ がない
正解: A
プライステイカーはいくら売っても価格が変わらないので $MR = P$（一定）。独占は売るほど価格を下げるので $MR$ は右下がり。だから条件も「$P = MC$」と「$MR = MC$」に分かれます。
🔒 3問すべて正解すると トピック3 が解放されます。

価格弾性力 — 値上げで売上は増える？減る？

価格を1%上げたとき需要が何%減るかを測る価格弾性力を学び、弾力的・非弾力的を見分けて「値上げで売上が増えるか減るか」を判断します。

// このトピックのゴール
  • 価格弾性力（1%値上げで需要が何%減るか）の意味を説明できる
  • 弾力的・非弾力的を区別し、身近な財を「代わりがあるか」で分類できる
  • 値上げで売上が増えるか減るかが弾性力で決まることを説明できる
①確認クイズ（全3問正解で出席パスワード解放）
Q1価格弾性力が表しているものは？
A価格を $1\%$ 上げたとき、需要が何 $\%$ 減るか（変化率の比）
B商品の値段そのものの大きさ
C商品が1年で何個売れるかの合計
正解: A
価格弾性力 $=\dfrac{\text{需要の変化率（\%）}}{\text{価格の変化率（\%）}}$ の絶対値。「$1\%$ 値上げで需要が何 $\%$ 減るか」という、値上げへの反応の敏感さを表します。
Q2あるブランド品を $10\%$ 値上げしたら需要が $5\%$ 減った。弾性力と、売上の動きの組み合わせとして正しいのは？
A弾性力 $2.0$（弾力的）→ 売上は減る
B弾性力 $0.5$（非弾力的）→ 売上は増える
C弾性力 $0.5$（非弾力的）→ 売上は減る
正解: B
弾性力 $= 5 \div 10 = 0.5 < 1$ なので非弾力的。客があまり逃げないので、値上げ分が数の減りを上回り売上は増えます（例: $1000$円×$100$個 $=10$万円 → $1100$円×$95$個 $=10.45$万円）。
Q3次のうち、もっとも「弾力的（値上げで客が大きく逃げる）」になりやすいのは？
A熱狂的なファンがついている人気ブランドのバッグ
B命にかかわる、代わりのない常用薬
Cどこのコンビニでも買える、ふつうのおにぎり
正解: C
弾力的かどうかを分けるのは「代わりがあるか」。どこでも買えるおにぎりは、値上げされたら別の店・別の商品にすぐ乗り換えられるので弾力的。ブランド品や代替のない薬は非弾力的です。
