// このトピックのゴール
  • 二階微分 f″(x) を計算できる（べき乗の公式をもう一回使うだけ）
  • f″ の符号と曲がり方（下に凸／上に凸）の対応を説明できる
  • 「増えているが鈍る」を f′ > 0 かつ f″ < 0 で表せる
①確認クイズ（全4問正解で トピック2 解放）
Q1$f(x) = x^3 - 6x^2 + 9x$ の二階微分 $f''(x)$ は？
A$3x^2 - 12x + 9$
B$6x - 12$
C$6x$
正解: B
$f'(x) = 3x^2 - 12x + 9$ をもう一回微分して $f''(x) = 6x - 12$。新しい技術は不要で、べき乗の公式（前に出して 1 減らす）をもう一回使うだけです。
Q2$f''(x) > 0$ の区間で、グラフの「曲がり方」はどうなっている？
A下に凸（おわん型）——傾きがどんどん増えていく
B上に凸（ドーム型）——傾きがどんどん減っていく
C右上がり（増加）になっている
正解: A
$f'' > 0$ は「傾き $f'$ が増えていく」＝グラフは下に凸（おわん型）。一階微分が「上り下り」、二階微分が「曲がり方」——役割の違いがこのトピックの核心です。
Q3スマホの充電率が「増え続けてはいるが、増えるペースはずっと鈍っている」。これを微分の符号で表すと？
A$c' < 0$ かつ $c'' > 0$
B$c' > 0$ かつ $c'' > 0$
C$c' > 0$ かつ $c'' < 0$
正解: C
「増えている」は $c' > 0$、「増え方が鈍る」は $c'' < 0$。2 つは別の情報で、両方そろって初めて「増えるけど鈍る」という曲線の様子が言い表せます。経済成長の鈍化も同じ構造です。
Q4区間 $0 < x < 5$ で $f(x) = x^2$ と $g(x) = -x^2 + 10x$ はどちらも右上がり。2 つの違いとして正しいのは？
A$f$ は傾きが増えていく加速型（$f'' = 2 > 0$）、$g$ は傾きが減っていく鈍化型（$g'' = -2 < 0$）
B右上がりという情報が同じなら、2 つのグラフの形も同じになる
C$f$ も $g$ も二階微分は正になる
正解: A
一階微分の符号（右上がり）が同じでも、二階微分の符号が違えば曲がり方は逆。$f = x^2$ は加速するおわん型、$g = -x^2 + 10x$ は鈍るドーム型です。

Q1極値の候補 $x = a$（$f'(a) = 0$ の場所）で $f''(a) < 0$ だった。この候補の判定は？
A山（極大）——あたりのグラフはドーム型（∩）に曲がっている
B谷（極小）——あたりのグラフはおわん型（∪）に曲がっている
C符号だけでは山か谷か判定できない
正解: A
二階の条件: 候補で $f''(a) < 0$ なら山（極大）、$f''(a) > 0$ なら谷（極小）。マイナスはドーム ∩、プラスはおわん ∪ と、記号の形がそのまま覚え方になります。
Q2利潤 $\pi(x) = -x^3 + 9x^2 - 15x$ の候補 $x = 5$ で $\pi''(x) = -6x + 18$ に代入すると $\pi''(5) = -12$。判定は？
A谷（極小）である
B判定できないので増減表に戻る
C山（極大）であり、極大値は $\pi(5) = 25$
正解: C
$\pi''(5) = -12 < 0$ なのでドーム型 ∩ ＝山（極大）。極大値は $\pi(5) = 25$ で、第10回に増減表で出した結論と完全に一致します。あのときの 3 行の表が、今回は代入 1 回で済みました。
Q3「一階の条件」と「二階の条件」のペアについて、役割分担として正しいのは？
A一階の条件で山谷を判定し、二階の条件で候補を出す
B一階の条件で候補を出し、二階の条件でその候補が山か谷かを判定する
Cどちらも同じ判定をするので、片方だけ使えばよい
正解: B
一階の条件（$f' = 0$）は「怪しい場所のリストアップ」、二階の条件（候補で $f''$ の符号を見る）は「一軒ずつの取り調べ」。①だけでも②だけでも完結しない、ペアで使う道具です。
Q4二階の条件と増減表の使い分けについて、正しい説明は？
A二階の条件はグラフ全体の上り下りも教えてくれるので、増減表の完全な上位互換である
B山か谷かだけ速攻で知りたいなら二階の条件、グラフ全体・区間つきの最大最小なら増減表。$f''(a) = 0$ のときは増減表に戻る
C増減表の方が常に速いので、二階の条件は使う場面がない
正解: B
二階の条件は「速いが守備範囲の狭い専門道具」。たとえば $f(x) = x^4$ は $x = 0$ が谷なのに $f''(0) = 0$ で判定不能——こういうときは慌てず増減表に戻れば判定できます。

// このトピックのゴール
  • 多項式を繰り返し微分して f(0), f′(0), f″(0), … を求められる
  • 階乗 n! の記号を使える
  • 係数回収 aₙ = f⁽ⁿ⁾(0) ÷ n! で元の多項式を復元できる
①確認クイズ（全5問正解で出席パスワード解放）
Q13 次の多項式 $f(x) = 2x^3 + 3x^2 + 4x + 5$ を微分し続けると、何回目で完全にゼロになる？
A3 回目
B何回微分してもゼロにはならない
C4 回目（$n$ 次式なら $n + 1$ 回目）
正解: C
3 次 → 2 次 → 1 次 → 定数 → ゼロ、と微分のたびに次数が下がる「微分の滝」。3 次式は 4 回目でゼロ、一般に $n$ 次式は $n + 1$ 回目でゼロになります。
Q2$x^3$ を 3 回微分すると定数 $6$ が残る（$x^3 \to 3x^2 \to 6x \to 6$）。この $6$ を階乗の記号で書くと？
A$6!$
B$3!$（$= 3 \times 2 \times 1 = 6$）
C$3^2$
正解: B
微分のたびに指数が係数に降りてきて $3 \times 2 \times 1 = 3! = 6$ が積み上がります。一般に $x^n$ を $n$ 回微分すると $n!$ が残る——これが係数回収の鍵です。
Q3ある 3 次関数の DNA（$x = 0$ での微分の値）のうち $f''(0) = 6$ だった。$x^2$ の係数 $a_2$ は？
A$a_2 = 6 \div 2! = 3$
B$a_2 = 6$ そのまま
C$a_2 = 6 \times 2! = 12$
正解: A
係数回収の公式は $a_n = f^{(n)}(0) \div n!$。$f''(0) = 6$ なら $a_2 = 6 \div 2 = 3$ です。微分で掛かってしまった「階乗のおまけ」を割って外す、というイメージです。
Q4「関数の DNA」というたとえが指しているものは？
A関数のグラフの形そのもの
B$f(x) = 0$ の解の一覧
C$x = 0$ での微分の値の一覧 $f(0), f'(0), f''(0), \ldots$ ——これだけで元の多項式が完全に復元できる
正解: C
式を隠されても、$f(0), f'(0), f''(0), f'''(0)$ の値さえあれば各係数が $a_n = f^{(n)}(0) \div n!$ で回収でき、多項式が完全に再現できます。生き物が DNA から復元できるように、です。これがテイラー展開のアイデアです。
Q5利潤 $\pi(x) = -x^3 + 9x^2 - 15x$ の DNA は $\pi(0) = 0,\ \pi'(0) = -15,\ \pi''(0) = 18,\ \pi'''(0) = -6$。回収される係数 $(a_0, a_1, a_2, a_3)$ は？
A$(0,\ -15,\ 18,\ -6)$ ——DNA の値がそのまま係数になる
B$(0,\ -15,\ 9,\ -1)$ ——各値を $n!$ で割ると元の式 $-x^3 + 9x^2 - 15x$ に戻る
C$(0,\ -15,\ 36,\ -36)$ ——各値に $n!$ を掛ける
正解: B
回収表: $0 \div 0! = 0$、$-15 \div 1! = -15$、$18 \div 2! = 9$、$-6 \div 3! = -1$。組み立て直すと $\pi(x) = -x^3 + 9x^2 - 15x$ ——第8回から付き合ってきた利潤関数が、微分の値 4 つから完全に復元できました。
